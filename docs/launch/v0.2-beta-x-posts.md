## 1｜beta 变更范围

iMM `v0.2.0-beta` 在 alpha 的规则/outbox 上已提供 paired-self iMessage gateway、App 内明确配对和手动发送、两个授权后台入口；签名 App 和 DMG 仍须证据后再宣称。beta 仍不稳定，行情提醒不是投资建议。项目：[仓库链接]

## 2｜paired-self 是什么

iMM `v0.2.0-beta` 的 paired-self gateway 只面向明确配对的本人，拒绝任意收件人；队列不接受临时电话号码/chat ID，也不读取联系人猜目的地。配对和 macOS 自动化权限由用户单独审查。说明：[协议链接]

## 3｜队列协议与幂等

iMM `v0.2.0-beta` 沿用 outbox 窄接口：JSON 仅有 `source`/`id`/`text`，正文 ≤4,000 UTF-8 字节；`id` 按规则和交易日期确定，gateway 以其幂等并在 ACK 持久化后移除文件。ACK 不含凭据。协议：[协议链接]

## 4｜发送仍是独立权限边界

iMM `v0.2.0-beta` 不会因打包 gateway 自动获得 Messages/自动化权限。发送需审查 gateway、paired-self 目的地和用户批准权限；iMM 不读 Messages 数据库、联系人或 chat ID，不支持号码群发。边界：[协议链接]

## 5｜后台安装的预期

iMM `v0.2.0-beta` 提供用户发起的 monitor 与 gateway companion 后台注册、停用和可核对卸载；两个 `SMAppService` 项均需单独批准，升级前按 gateway→monitor 停用，恢复时按 monitor→gateway 启用。beta 不绕过授权或隐藏运行。安装说明：[仓库链接]

## 6｜签名 App 与 DMG 的核验

iMM `v0.2.0-beta` 只有在签名验证和 DMG 校验有证据后，才会宣称“签名 App/DMG”。文件存在不等于签名有效；发布前不拿占位链接冒充结果。核验：[签名链接]；DMG：[DMG 链接]

## 7｜本地数据和密钥边界

iMM `v0.2.0-beta` 的 gateway 扩展保持本地优先：无遥测、广告、云账户或联系人同步；规则/状态/outbox 在本机，Alpha Vantage key 经 Keychain 读取。安装包、日志、ACK 不应含个人路径、消息正文或凭据。隐私：[仓库链接]

## 8｜行情风险不会因 beta 消失

iMM `v0.2.0-beta` 仍使用选择的数据源和规则；行情可能延迟、缺失或修订，Cboe VIX/Alpha Vantage 的许可、条款和速率限制需自行核对。paired-self 只改变消息交接，不提高准确率，也不是投资建议。项目：[仓库链接]

## 9｜候选用户范围

`v0.2.0-beta` 候选用户需 macOS 14+，愿审查 gateway 协议、Keychain/自动化权限，只向配对本人发送并接受 beta 不稳定；不面向任意收件人、群发、联系人发现或收益承诺。候选入口：[候选链接]

## 10｜候选用户的安全试用边界

iMM `v0.2.0-beta` 候选试用先验证规则、outbox JSON、幂等 ACK 和 paired-self，再决定是否实际发送；不要使用真实联系人、敏感消息或未经核对的脚本。候选资格不代表行情或收益结果。说明：[候选链接]

## 11｜与已有 gateway 的关系

iMM `v0.2.0-beta` 不假定既有个人 gateway 可直接兼容。接入前检查字段白名单、权限、幂等 ACK、paired-self 和回滚；不覆盖既有配置，也不把个人路径或凭据放进 issue、截图或日志。适配：[协议链接]
