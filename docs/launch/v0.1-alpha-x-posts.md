## 1｜项目定位

iMarketMessage（App 名 iMM）计划于[发布日期]公开 `v0.1.0-alpha`。这是 macOS 14+ 原生、本地优先的行情提醒工具：按代码、数据源、指标和阈值评估规则，把触发消息写入本机 outbox。它不是投资建议。源码：[仓库链接]

## 2｜规则能力

iMM `v0.1.0-alpha` 支持 AND 条件、收盘价/日涨跌幅、`>=`/`<=`/`>`/`<`、“仅首次进入区域”和交易日冷却。冷却按工作日近似，不等同交易所日历；只执行条件，不替用户决定买卖，也不是投资建议。说明：[仓库链接]

## 3｜数据源与风险

iMM `v0.1.0-alpha` 提供 Cboe VIX 日线（无需 key）和 Alpha Vantage 日线（用户自备 key，经 macOS Keychain 读取）。行情可能延迟、缺失或修订；许可、条款和速率限制由使用者核对。不是投资建议。项目：[仓库链接]

## 4｜本地优先与隐私边界

iMM `v0.1.0-alpha` 无遥测、广告、云账户、联系人同步或 Messages 数据库读取。规则、状态、outbox 留在本机；API key 不写规则 JSON、日志或仓库，也不保存电话号码/chat ID。真实 iMessage 不属于 alpha。隐私：[仓库链接]

## 5｜开发者运行路径

macOS 14+、Swift 6：`swift build --scratch-path /tmp/imarketmessage-build`、`swift test --scratch-path /tmp/imarketmessage-test`；App：`swift run --scratch-path /tmp/imarketmessage-app iMM`。CLI 与清理说明：[运行说明]。测试不联网、不发消息。

## 7｜iMessage 交接边界

iMM `v0.1.0-alpha` 向 outbox 写 `source`、`id`、`text` 三字段 JSON；正文上限 4,000 UTF-8 字节，目录/文件私有。授权 gateway 才能消费；alpha 不装 gateway、不读联系人或 Messages 数据库、不发 iMessage。协议：[仓库链接]
